# Ballistic Pendulum & Ramp Collision Lab

An interactive HTML/CSS/JS physics simulation for **The Thinking Experiment** covering two classic multi-stage conservation problems:

1. **Ballistic Pendulum**: A projectile ball fires into a suspended catcher, collides perfectly inelastically, and swings to a maximum height $h$.
2. **Circular Ramp & Friction Slide**: A mass $m_1$ drops from rest down a frictionless circular ramp of radius $R$, collides perfectly inelastically with $m_2$, and slides across a rough surface ($\mu$) to a stop.

## Live Simulation
- **Live Site:** https://thinking-experiment-sims.github.io/ballistic-pendulum-sim/
- **Simulation Hub:** https://thinking-experiment-sims.github.io/interactive-physics/

## Running Locally & Testing
Open `index.html` directly in any browser (no build step required), and run the physics unit tests with:

```bash
npm test
```
